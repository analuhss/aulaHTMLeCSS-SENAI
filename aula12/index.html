BOX MODEL

Content(conteúdo)

Define a largura da caixa(salvo elementos de bloco)

Padding

Separa o contúdo das bordas da caixa. É a imagem interna

Border(borda)

define bordas para a caixa

Margin(margem)

Define a distância entre uma caixa e outra

Widht(Largura)

A largura total da caixa, por padrão é somatório do conteúdo + padding(left/right) + border (left/right)

Height(Altura)

A altura total da caixa, por pad´rap é o somatório do conteúdo + padding (top/bottom) + border (top/bottom)
