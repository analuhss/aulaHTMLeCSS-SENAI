O que é semântica na HTML?

Semântica na HTML significa usar as tags cetas para tipo de conteúdo, ajudando navegadores, mecanismos de buscas e leitores de tela a entenderem melhor a estrutura da página.

Benefícios do HTML semântico?

Melhora a acessibilidade (Leitores de tela conseguem interpretar melhor)

Facilita a manutenção do código(códigos mais organizafos e legível)

Ajuda na responsividade (tags semânticas trabalham melhor com CSS e JS)

A parte main é aparte principal do seu site, enquanto main serve para colocar informações referente a informações
